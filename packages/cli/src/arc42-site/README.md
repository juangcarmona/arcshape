# ArcShape static site renderer

The self-contained arc42 renderer is adapted from Raccord's `arc42-snapshot` tool and retains its MIT license and notice in this directory. It validates the Markdown section contract, sanitizes rendered HTML, and pre-renders accessible Mermaid diagrams into one navigable HTML file. ArcShape's canonical source is `docs/architecture/NN-slug/README.md` plus supporting Markdown in each section directory; legacy flat `NN-slug.md` sources remain supported.
