# 12. Glossary

| Term                       | Definition                                                                                                             |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Architecture documentation | Markdown description of a system's structure, behavior, constraints, and quality attributes.                           |
| arc42                      | A twelve-section template for communicating software architecture.                                                     |
| Analysis session           | Local state that tracks repository evidence, review coverage, findings, leads, questions, and resume progress. |
| Canonical Markdown         | Repository-authored documentation from which validation and reader outputs are derived.                                |
| ProductShape               | The product-definition-as-code model that states what ArcShape is intended to do.                                      |
| Reader site                | Self-contained static web output generated from canonical architecture Markdown.                                       |
