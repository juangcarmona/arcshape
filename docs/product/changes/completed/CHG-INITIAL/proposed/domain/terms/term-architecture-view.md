## Definition

A presentation of architecture documentation intended to help a reader understand a software system.

## Distinguish From

The view presents architecture documentation; it is not a separate source of architecture truth.

## Usage

ArcShape is intended to generate a reader-friendly web view. Whether the first release also publishes or hosts that view remains open.
