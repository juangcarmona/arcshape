## Intended Outcome

The maintainer has useful architecture documentation that can be kept aligned with the repository and shared with its stakeholders.

## Entry Conditions

The maintainer has a software repository and wants to document its architecture.

## Journey Narrative

The maintainer brings ArcShape into the repository, provides or reviews relevant context, and works with the available assistant workflow to create and maintain arc42 architecture documentation. The maintainer then makes the documentation available to readers through the supported architecture view.

## Variants and Branches

The repository may or may not contain an approved ProductShape definition. Installation and publication methods are not yet decided.

## Completion Conditions

The maintainer has reviewed architecture documentation and can share a reader-facing view of it.
