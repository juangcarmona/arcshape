## Constraint

ArcShape's architecture-documentation workflows use the arc42 framework.

## Rationale

The product is intended to create and maintain architecture documentation using an established framework that supports communication across stakeholder groups.

## Consequences

ArcShape's documentation outcomes must align with arc42. The exact mapping, customization boundaries, and supported arc42 sections remain product details to be defined during product refinement.
