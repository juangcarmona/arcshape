## Purpose

Maintains a software repository and needs its architecture to remain documented and understandable as the system changes.

## Goals

- Establish architecture documentation for a repository.
- Keep the documentation aligned with the evolving system.
- Share the architecture with people who need to understand it.

## Responsibilities

- Chooses when to create, review, update, and share architecture documentation.
- Supplies context and evaluates proposed documentation.
- Decides whether connected product-definition artifacts are relevant.

## Boundaries

The maintainer owns the repository and product decisions. ArcShape assists with documentation but does not become the authority for product intent or architecture decisions.
