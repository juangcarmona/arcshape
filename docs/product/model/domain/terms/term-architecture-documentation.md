## Definition

A maintained description of a software system's architecture, intended to help its stakeholders understand the system and its important design decisions.

## Distinguish From

It is not the system's product definition, source code, or a single rendered view of its content.

## Usage

ArcShape helps a repository maintainer create and maintain architecture documentation using the arc42 framework.
