## Responsibility

Describes, maintains, and presents knowledge about a software system's architecture.

## Language

Architecture documentation explains a system's purpose, boundaries, structure, runtime behavior, and important design decisions. An architecture view is a reader-facing presentation of that documentation. An approved product definition records product intent and remains distinct from architecture documentation.

## Boundaries

This context covers architecture-documentation outcomes, not the implementation architecture of ArcShape itself, the product definition of an adopting repository, or the internal design of any AI assistant.

## External Relationships

It may use repository evidence and connect to an approved ProductShape definition. The exact integration depth and supported repository environments are open product decisions.
